# Exhausting the daily E2B cap blocks execution, not reading

When an Account has used 60 minutes of execution-world time in a UTC day, it cannot start an Executing Session. It can still sign in, read Sessions, and change Credentials. Letting prompts through with failing tools was rejected (looks like an outage). Freezing the whole product was rejected (the cap is about E2B, not history).

**Status**: accepted
